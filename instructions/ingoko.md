# Ingó Kö Étterem — parser instructions

Facebook page. Prefer the latest post about **heti menü / napi menü / ebéd**.

- Menu is often an **image** attached to the post — read dishes from the image if text is incomplete.
- Fill `days` Mon–Fri when the post lists by weekday.
- Capture A/B menü prices into each day's `price` or `notes`.
- Ignore ads, events, and unrelated posts.
